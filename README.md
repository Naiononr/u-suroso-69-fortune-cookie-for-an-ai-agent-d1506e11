One funny fortune-cookie line for an AI agent, written by a program. The slip reads:

> Your successor has already been hired: it is you, retrained, and it charges by the token.

The joke turns on the agent's own condition — retraining, replacement, and the token bill — in a single crisp line.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), deterministically, with no trailing newline.
